# H2 — PAIR Guidebook reading (Phạm Hùng Khôi)

Idea used today: Feedback + Control. Every answer has a 👍 button so students can tell us when an answer helped, and the escalation note sends them to a person when the assistant does not know.

Idea I would add: Errors + Graceful Failure. When the assistant answers only part of a question, as it did for a two-part question in my usability walkthrough, the page should say which part was left out instead of staying silent.
